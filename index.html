Diseño e Implementación de una Infraestructura Informática para una Pequeña Empresa

Entorno virtualizado centralizado para gestionar equipos, red local, usuarios, recursos compartidos, acceso remoto y copias de seguridad de forma segura y eficiente.

1. Descripción y Justificación

Por qué es necesaria una infraestructura organizada en el día a día de una pyme.

El Problema a Resolver

Cualquier pequeña empresa depende de sus equipos, red y servicios para trabajar sin interrupciones. Sin una configuración adecuada aparecen fallos de conectividad, descontrol de permisos, pérdida de archivos o accesos no autorizados.

La Solución Propuesta

Simular mediante virtualización una infraestructura real basada en Linux: servidor central para servicios de red (DHCP y DNS), compartición de carpetas por departamentos con Samba, administración remota segura por SSH y respaldo automático con rsync.

Nota sobre el alcance del proyecto: El anteproyecto sirve como guía inicial. Durante la fase de desarrollo se prioriza que el núcleo de sistemas y red funcione al 100 % con total estabilidad, adaptando o descartando módulos secundarios si no aportan valor crítico al entorno.

2. Objetivos Principales

Metas técnicas definidas para validar la infraestructura.

Red Local Funcional

Diseñar el direccionamiento IP y configurar una LAN virtualizada que comunique servidor y clientes con salida controlada.

Servicios Esenciales

Desplegar asignación automática de direcciones mediante DHCP y resolución interna de nombres con DNS (BIND9).

Usuarios y Permisos

Estructurar grupos y carpetas compartidas en Samba garantizando que cada perfil acceda solo a su información.

Seguridad y Control

Habilitar la administración remota mediante SSH y aplicar políticas básicas de protección en el servidor.

Copias de Seguridad

Implementar respaldos periódicos con rsync y scripts en Bash verificando la restauración de datos.

Pruebas y Documentación

Validar cada servicio con herramientas de diagnóstico (ping, ip a, nslookup) y documentar los resultados.

3. Arquitectura y Stack Tecnológico

Esquema lógico del entorno virtualizado y herramientas empleadas.

Topología Lógica del Entorno (VirtualBox)
Equipo Anfitrión Hardware Físico · VirtualBox
➔
Ubuntu Server DHCP · DNS (BIND9) · Samba · SSH · rsync
⇄
Red Local (LAN) Segmento Interno Empresa
⇄
Ubuntu Desktop Equipos Cliente · Pruebas de Acceso

VirtualBox

Núcleo

Hipervisor para desplegar las máquinas virtuales del servidor y los equipos cliente sobre un único equipo físico.

Ubuntu Server / Desktop

Núcleo

Sistemas operativos base: edición Server sin entorno gráfico para servicios y Desktop para simular puestos de trabajo.

DHCP + DNS (BIND9)

Núcleo

Automatización de parámetros de red en los clientes y resolución de nombres de dominio internos de la empresa.

Samba

Núcleo

Servidor de archivos en red para compartir directorios corporativos con control de acceso por usuarios y grupos.

SSH + Bash + rsync

Núcleo

Administración remota cifrada, automatización de tareas mediante scripts y copias de seguridad incrementales.

MySQL (Incidencias)

Ampliable

Base de datos relacional (tablas EMPLEADOS e INCIDENCIAS) planteada para registrar averías técnicas.
